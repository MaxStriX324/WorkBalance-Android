# Политика конфиденциальности WorkBalance

Последнее обновление: 8 сентября 2026 года

[English version](PRIVACY.md)

WorkBalance — локальное приложение для планирования рабочего времени. Регистрация не требуется.

## Данные на устройстве

В локальной базе и настройках Android хранятся:

- время входов и выходов;
- дневная норма и длительность обязательного обеда;
- ручные типы дней и запланированные отсутствия;
- введённое пользователем название рабочего места;
- настройки производственного календаря;
- настройки локальных напоминаний;
- выбранный язык приложения;
- настройка проверки обновлений в варианте для GitHub.

## Передача данных

В приложении нет аналитики, рекламы, аккаунтов или собственного удалённого сервера. Рабочие отметки, название работы и настройки не отправляются разработчику.

Вариант `github` может запросить через GitHub API публичный список релизов репозитория `MaxStriX324/WorkBalance-Android`. Запрос содержит обычные сетевые сведения, доступные GitHub, и номер установленной версии в строке user-agent, но не содержит рабочие отметки. Автоматическую проверку можно отключить.

Варианты `play` и `rustore` не содержат встроенной проверки обновлений и не запрашивают разрешение Android на интернет.

Производственные календари встроены в приложение и не загружаются с сервера.

## Экспорт и резервная копия

JSON и CSV создаются только по явному действию пользователя через системный выбор файла Android. После передачи файла выбранному хранилищу или приложению пользователь самостоятельно отвечает за его защиту.

JSON содержит введённое название рабочего места и точное время отметок. В нём нет аккаунта Android, аппаратного или рекламного идентификатора, номера пропуска и автоматически собранных сведений о личности.

## Разрешения Android

- Уведомления используются для необязательных напоминаний об обеде и забытых отметках.
- Запуск после перезагрузки используется только для восстановления расписания локальных напоминаний.
- Интернет присутствует только в варианте для GitHub и нужен для чтения публичного списка релизов.

Доступ к геопозиции, контактам, камере, микрофону, звонкам и SMS не запрашивается.

## Удаление данных

Отдельные отметки можно удалить в приложении. Удаление WorkBalance или очистка его данных удаляет локальную базу и настройки с устройства. Ранее экспортированные файлы необходимо удалить отдельно из выбранного хранилища.
