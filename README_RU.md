# WorkBalance для Android

[English version](README.md)

WorkBalance — локальное Android-приложение для учёта входов, выходов, обязательного обеда и месячного баланса рабочего времени. Оно рассчитано на график, в котором часы можно перераспределять между днями, сохраняя общий план месяца.

> Это независимый инструмент планирования, а не официальный табель. Результаты нужно сверять с правилами и данными работодателя.

## Возможности

- большая кнопка «Вошёл / Вышел» и несколько интервалов за день;
- просмотр, добавление, исправление и удаление отметок любого дня;
- разделение обязательного обеда и дополнительного отсутствия;
- настраиваемая дневная норма и обед, включая режимы `8:00 + 1:00` и `4:00 + 0:30`;
- дневной и месячный баланс, расчёт времени ухода и прогноз;
- планируемые отсутствия без уменьшения месячной нормы;
- статистика и прогресс месяца;
- производственный календарь России на 2026 год и отдельный календарь Саратовской области;
- настройка учёта сокращённых дней;
- локальные напоминания об обеде и забытом входе или выходе без геолокации;
- виджет и плитка быстрых настроек;
- полная резервная копия JSON и восстановление;
- локализованный экспорт месяца в CSV;
- русский и английский интерфейс с переключателем в настройках;
- отсутствие регистрации, рекламы, аналитики и собственного сервера.

## Как считается обед

```text
Зачтено = присутствие − max(0, обязательный обед − выходы за территорию)
```

Время вне территории сначала покрывает официальный обед. Всё сверх длительности обеда показывается отдельно как дополнительное отсутствие. При обеде `0 минут` обеденные показатели скрываются.

Подробности: [расчёт](docs/CALCULATION.md), [производственный календарь](docs/PRODUCTION_CALENDAR.md), [напоминания](docs/REMINDERS.md).

## Конфиденциальность

Отметки хранятся в локальной базе Room. Если на устройстве включено системное резервное копирование Android, база и настройки могут сохраняться через выбранного на устройстве провайдера резервных копий. Вариант для GitHub использует интернет только для чтения публичного списка релизов; проверку можно отключить. В вариантах Google Play и RuStore встроенный обновлятор и разрешение на интернет отсутствуют. Экспорт JSON и CSV выполняется только по явному действию пользователя.

Подробнее: [политика конфиденциальности](PRIVACY_RU.md).

## Варианты сборки

| Вариант | Назначение | Проверка GitHub | Интернет |
|---|---|---:|---:|
| `github` | GitHub Releases и передача APK | Да | Да |
| `play` | Google Play | Нет | Нет |
| `rustore` | RuStore | Нет | Нет |

У вариантов одинаковые `applicationId`, база и формат резервной копии. Данные сохранятся при обновлении, если увеличить `versionCode` и подписать новую сборку тем же ключом.

## Сборка

Нужны Android Studio, Android SDK Platform 36 и JDK 17.

```powershell
.\gradlew.bat testGithubDebugUnitTest assembleGithubDebug
```

Результат:

```text
app\build\outputs\apk\github\debug\app-github-debug.apk
```

Подробности: [docs/BUILDING.md](docs/BUILDING.md).
