# Производственный календарь

WorkBalance хранит официальные особенности календаря отдельными JSON-пакетами по годам. Приложение не пытается бесконечно повторять календарь 2026 года: если данных на новый год ещё нет, оно показывает предупреждение и временно считает план по обычной рабочей неделе.

## Данные версии 0.6.0

- Россия, 2026: федеральные праздники и переносы по постановлению Правительства РФ от 24.09.2025 № 1466;
- Саратовская область, 2026: Радоница 21 апреля по Закону Саратовской области от 22.03.2012 № 26-ЗСО и сокращение 20 апреля на один час;
- предпраздничные сокращения России: 30 апреля, 8 мая, 11 июня и 3 ноября.

Контрольные нормы для графика 8 часов, понедельник–пятница, при автоматическом учёте сокращений:

| Календарь | Рабочие дни | Норма за 2026 год | Норма апреля |
|---|---:|---:|---:|
| Россия | 247 | 1972:00 | 175:00 |
| Саратовская область | 246 | 1963:00 | 166:00 |

## Настройки пользователя

Федеральные праздники и региональные праздники включаются независимо. Для сокращённых дней предусмотрены три режима:

- `Спрашивать` — приложение предлагает учесть сокращение в конкретную дату;
- `Учитывать автоматически` — норма дня сразу уменьшается;
- `Не учитывать` — норма остаётся полной.

Ручной тип или норма дня всегда важнее встроенного календаря. Это позволяет повторить фактические правила конкретного работодателя.

## Добавление следующего года

Для нового года добавляется федеральный файл `app/src/main/assets/calendars/ru-ГГГГ.json`. При необходимости рядом добавляются региональные пакеты, например `ru-saratov-ГГГГ.json`. Затем их нужно зарегистрировать в `ProductionCalendarProvider` и проверить контрольными тестами месячные и годовую нормы.

Пакет содержит только исключения из обычной рабочей недели:

```json
{
  "id": "RU-2027-r1",
  "year": 2027,
  "regionCode": null,
  "title": "Россия, 2027",
  "revision": "2027-01-01",
  "status": "OFFICIAL",
  "source": "Реквизиты официального документа",
  "rules": [
    { "date": "2027-01-01", "type": "DAY_OFF", "name": "Новогодние каникулы" },
    { "date": "2027-04-30", "type": "SHORTENED", "name": "Предпраздничный день", "reductionMinutes": 60 }
  ]
}
```

Поддерживаемые типы правил:

- `DAY_OFF` — дата не требует рабочей нормы;
- `WORKDAY` — дата рабочая даже при обычном выходном;
- `SHORTENED` — рабочая норма уменьшается на `reductionMinutes` согласно выбранному режиму.

Пока автоматическое скачивание пакетов не реализовано, календарь следующего года поставляется с обновлением приложения. Архитектура пакетов позволяет позже добавить проверяемый импорт без изменения расчётного ядра.
