# Алгоритм расчёта времени

## Термины

- **Присутствие** — сумма всех завершённых интервалов `вход → выход`; для открытого интервала используется текущее время.
- **Общий интервал** — время от первого входа до последнего выхода или текущего момента.
- **Время вне территории** — общий интервал минус присутствие.
- **Обязательный обед** — продолжительность, заданная в настройках графика.
- **Обед вне территории** — часть выходов в пределах обязательной продолжительности обеда.
- **Дополнительное отсутствие** — часть выходов сверх обязательной продолжительности обеда.
- **Зачтённое время** — присутствие после вычета недостающей части обеда.

## Формулы

```text
outside = max(0, totalSpan − presence)
lunchOutside = min(outside, requiredLunch)
extraOutside = max(0, outside − requiredLunch)
missingLunch = max(0, requiredLunch − outside)
credited = max(0, presence − missingLunch)
dayBalance = credited − requiredWork
```

Выходы между первым входом и окончанием рабочего дня сначала покрывают обязательный обед. Дополнительный вычет не применяется к той части обеда, которая уже проведена вне территории.

## Примеры

| Отметки | Присутствие | Вне территории | Доп. вычет | Зачтено при обеде 1:00 |
|---|---:|---:|---:|---:|
| 09:00 вход, 18:00 выход | 9:00 | 0:00 | 1:00 | 8:00 |
| 09:00 вход, 13:00 выход, 14:00 вход, 18:00 выход | 8:00 | 1:00 | 0:00 | 8:00 |
| 09:00 вход, 13:00 выход, 13:20 вход, 18:00 выход | 8:40 | 0:20 | 0:40 | 8:00 |
| 09:00 вход, 13:00 выход, 14:30 вход, 19:00 выход | 8:30 | 1:30 | 0:00 | 8:30 |

## Месячный план

По умолчанию рабочими считаются понедельник–пятница. Если включён производственный календарь, он меняет норму для официальных праздников, переносов и сокращённых дней. Норма месяца — сумма дневных норм всех дней с учётом этих правил и ручных переопределений.

Приоритет источников нормы дня, от самого высокого к самому низкому:

1. ручная норма или тип дня, выбранные пользователем;
2. решение пользователя по конкретному сокращённому дню;
3. региональный производственный календарь;
4. федеральный производственный календарь;
5. обычный график по дням недели.

В режиме сокращённых дней `Спрашивать` полная норма сохраняется до ответа пользователя. Ответ записывается как норма конкретной даты. В режиме `Учитывать автоматически` указанное календарём сокращение сразу вычитается из нормы дня. Режим `Не учитывать` оставляет полную норму.

Типы `праздник`, `выходной`, `отпуск`, `больничный` и `отгул` имеют нулевую рабочую норму. `Рабочий день` и `командировка` используют норму текущего графика.

Тип `Не буду, отработаю заранее` сохраняет норму дня в плане месяца, но исключает дату из доступных для отработки дней. Поэтому оставшиеся часы распределяются между днями, когда пользователь планирует присутствовать.

```text
monthPlan = sum(requiredWork for every day)
remaining = max(0, monthPlan − creditedMonth)
remainingAtDayStart = max(0, monthPlan − creditedBeforeToday)
averageDailyTarget = ceil(remainingAtDayStart / availableDaysIncludingToday)
```

Для текущего рабочего дня показатель «Нужно в среднем» означает полный целевой зачёт за день, а не количество часов, которое осталось провести сегодня. Поэтому уже отработанная сегодня часть не уменьшает среднюю цель в течение дня. Запланированные отсутствия исключаются из количества доступных дней, но их часы остаются в плане.

## Время ухода

- **По норме** — момент, когда сегодняшний зачёт достигнет дневной нормы.
- **До нулевого баланса** — подсказка, сколько ещё нужно зачесть сегодня и до какого времени остаться, чтобы компенсировать минус предыдущих дней.
- **По плану месяца** — рекомендуемый выход с учётом месячного остатка и отмеченных будущих отсутствий.

Пока обязательный обед ещё не покрыт выходами, прогноз дополнительно учитывает его оставшуюся часть. Поэтому время выхода корректно рассчитывается и в течение первого часа после входа.

## Ограничения

Реальные системы учёта могут применять округление, фиксированное окно обеда, минимальную длительность выхода, ночные смены и другие правила. Эти варианты должны добавляться только после проверки на обезличенной фактической выгрузке.

Официальные производственные календари поставляются отдельными годовыми пакетами. Если пакета на выбранный год нет, приложение использует обычный график по дням недели и показывает предупреждение: такой план нельзя считать официальным до установки календаря нужного года.
