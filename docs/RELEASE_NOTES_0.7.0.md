# WorkBalance 0.7.0

В этой версии появились необязательные локальные напоминания о забытом входе и выходе.

## Что нового

- Проверка отсутствия входа в выбранное время рабочего дня.
- Напоминание о выходе после расчётного выполнения дневной нормы и дополнительной задержки.
- Быстрые действия прямо в уведомлении: поставить отметку, напомнить позже или отметить отсутствие.
- Автоматический пропуск выходных, праздников, отпуска, больничного, командировки и запланированного отсутствия.
- Восстановление расписания после перезагрузки телефона и обновления приложения.
- Перенос новых настроек через JSON-резервную копию.

Функция изначально выключена. Включить её можно в `Настройки → Забытые отметки`.

Перед установкой обновления рекомендуется экспортировать JSON-резервную копию. Для обновления поверх старой версии APK должен быть подписан тем же ключом; данные Room при этом сохраняются.
