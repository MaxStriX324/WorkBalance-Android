# Напоминания

WorkBalance создаёт напоминания локально через Android `AlarmManager`. Сервер, аккаунт и геолокация не используются.

## Забытый вход

В указанное пользователем время приложение проверяет текущий день. Уведомление появляется, если одновременно выполнены условия:

- функция включена;
- у дня есть рабочая норма;
- за день нет ни одной отметки входа;
- день не отмечен как командировка или «Не буду, отработаю заранее».

Выходные, праздники, отпуск, больничный и отгул имеют нулевую норму и автоматически пропускаются. Следующая проверка планируется на ближайший доступный рабочий день.

## Забытый выход

После входа приложение рассчитывает время выполнения дневной нормы с учётом обязательного обеда. Уведомление планируется на этот момент плюс выбранная задержка. После выхода оно отменяется. Если сотрудник вышел на обед и затем вернулся, время рассчитывается заново.

## Действия уведомления

- `Войти сейчас` и `Выйти сейчас` создают отметку с текущим временем, только если она соответствует текущему состоянию;
- `Напомнить позже` переносит эту проверку на выбранный интервал;
- `Сегодня не работаю` устанавливает тип дня «Не буду, отработаю заранее»: месячная норма сохраняется, но день исключается из доступных для распределения часов.

После перезагрузки устройства и установки обновления Android расписание создаётся заново. Срабатывание может быть с небольшой задержкой из-за системного энергосбережения.
