# WorkBalance 0.8.0

[Русский](#русский) · [English](#english)

## Русский

Версия 0.8.0 делает приложение двуязычным и готовит проект к публикации на площадках.

- Полный русский и английский интерфейс.
- Выбор языка в настройках с немедленным применением.
- Переведены уведомления, виджет, плитка, инструкция и CSV-отчёт.
- Отдельные сборки для GitHub, Google Play и RuStore.
- `targetSdk 36` для актуальных требований Android.
- Обновлённые англоязычные README и политика конфиденциальности.

Существующие отметки сохраняются при установке поверх предыдущей версии, если APK подписан прежним ключом.

## English

Version 0.8.0 adds complete English localization and prepares the project for store distribution.

- Complete Russian and English interfaces.
- In-app language selector with immediate application.
- Localized notifications, widget, Quick Settings tile, instructions, and CSV reports.
- Separate GitHub, Google Play, and RuStore build variants.
- Target SDK 36 for current Android distribution requirements.
- English and Russian README and privacy policy.

Existing records are preserved when the update is installed over the previous version with the same signing key.
