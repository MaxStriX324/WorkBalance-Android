# Форматы экспорта

## JSON-резервная копия

Текущий `formatVersion` равен `1`.

```json
{
  "format": "ru.maxstrix.workbalance.backup",
  "formatVersion": 1,
  "settings": {
    "workplaceName": "Работа",
    "workMinutes": 480,
    "lunchMinutes": 60,
    "lunchReminderEnabled": true,
    "lunchReminderLeadMinutes": 15
  },
  "events": [
    { "at": "2026-09-02T08:45", "type": "IN" },
    { "at": "2026-09-02T18:03", "type": "OUT" }
  ],
  "dayOverrides": []
}
```

Время сохраняется как локальные ISO-8601 дата и время без часового пояса, чтобы старые отметки не смещались при поездке или изменении часового пояса телефона.

Импорт сначала проверяет идентификатор формата, версию, даты, типы событий и диапазоны настроек. Замена базы выполняется одной транзакцией только после успешного разбора всего файла.

## CSV месяца

CSV использует UTF-8 с BOM, разделитель `;` и заключает каждую ячейку в кавычки для корректного открытия в русской версии Excel.

Колонки:

| Колонка | Содержание |
|---|---|
| Дата | ISO-дата дня |
| День недели | Русское название |
| Норма | Требуемое время |
| Первый вход | Первая корректная отметка IN |
| Последний выход | Последняя корректная отметка OUT |
| Отметки | Исходная последовательность событий |
| На территории | Сумма интервалов присутствия |
| Вне территории всего | Все перерывы между интервалами |
| Обед вне территории | Часть выходов в пределах обязательной нормы обеда |
| Обед на территории | Недостающая часть обязательного обеда, вычтенная из присутствия |
| Дополнительное отсутствие | Время выходов сверх нормы обеда |
| Зачтено | Итоговое рабочее время |
| Баланс | Разность зачёта и нормы |
| Предупреждения | Ошибки последовательности отметок |

CSV предназначен для анализа и сверки, а не для восстановления базы. Для восстановления используется только JSON.
