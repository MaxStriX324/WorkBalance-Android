# Участие в разработке

## Ошибка

В issue желательно указать:

1. версию приложения и Android;
2. последовательность действий;
3. ожидаемый и фактический результат;
4. обезличенный пример отметок;
5. журнал сборки или stack trace, если ошибка связана со сборкой.

Не публикуйте ключи подписи, пароли, резервные копии с реальными отметками, ФИО, название организации, номера пропусков или внутренние документы.

## Изменение кода

1. Создайте отдельную ветку.
2. Сохраните текущий стиль Kotlin и Compose.
3. Для изменения расчёта добавьте тест в `app/src/test`.
4. Выполните:

```bash
./gradlew test assembleDebug
```

5. Опишите изменение и его влияние на существующие данные.

Изменение схемы Room должно сопровождаться миграцией и тестом обновления базы.
